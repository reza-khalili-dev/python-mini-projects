# Digikala HTML Scraper

A Python script that uses Selenium to fetch the complete HTML content of Digikala's mobile phones page.

## Features
- Automatically downloads and manages ChromeDriver
- Waits 120 seconds for full page load (including JavaScript content)
- Prints the complete HTML source code
